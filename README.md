# Файл знакомства с ООП

## Описание
Функционал:
* Реализован шаблон представления продукта (`Procuct`)
* Реализован шаблон представления категорий продуктов (`Category`)
с автоматическими счетчиками кол-ва продуктов и кол-ва категорий
* Реализован функция прочтения и конвертирования в объекты данные из JSON-файла
(Для проверки работоспособности конвертера, зайдите в `src/utils.py`, раскомментируйте `if __name__...` блок
и запустите файл `utils.py`)
* Реализован шаблон для продуктов узкой специализации(`Smartphones` и `LawnGrass`)
* Реализованы абстрактные классы для Product и Category
* Реализован миксин для информирования об инициализации Product и дочерних классов
* Реализованы возбуждение и обработка исключений в `Product`(если кол-во товара == 0) и в `Category`

* (Для просмотра процента покрытия кода тестами - `htmlcov/index.html`)
***
`Класс Product`

Принимает данные:
* name - название
* description - описание
* price - цена
* quantity - количество

Имеет функционал:
* инициализация
* пользовательская информация о классе
* метод сложения двух классов Product
* класс-метод создания нового продукта
* геттера и сеттера цены

Класс Product имеет дочерние `Smartphones` и `LawnGrass`

`Smartphones` принимает данные:
* name - название
* description - описание
* price - цена
* quantity - количество
* efficiency - производительность 
* model - модель
* memory - объем встроенной памяти
* color - цвет

`LawnGrass` принимает данные:
* name - название
* description - описание
* price - цена
* quantity - количество
* country - страна-производитель
* germination_period - срок прорастания
* color - цвет

Оба имеют функционал:
* инициализация
* метод сложения двух одинаковых классов 
***
`Класс Category`

Принимает данные:
* name - название
* description - описание
* products - список продуктов

Имеет функционал:
* инициализация
* пользовательская информация о классе
* количество задач в категории
* метод работы по индексу в products
* метод добавления продукта в products
* геттер вывода на экран продуктов в products
***
## Установка

1. Клонировать репозиторий
  ```
  git clone https://github.com/VikVyaz/OOP_claster
  ```
2. Установка зависимостей
  ````
  pip install -r requirements.txt
  ````

## Использование

1. Следовать пункту ***Установка***
2. Запустить ``main.py`` (на данном этапе выводит данные по заготовленному шаблону)
